# Users Table


## Стек

React 18+, TypeScript, MobX, Vite, Vitest.

## Функциональность

- Таблица пользователей: фамилия, имя, возраст, пол, телефон, email, страна, город
- Сортировка по фамилии, имени, возрасту, полу, телефону — 3 состояния (по возрастанию / по убыванию / без сортировки), реализована через серверные HTTP-запросы (`sortBy`, `order`) к dummyjson
- Пагинация
- Поиск по всем полям через серверный эндпоинт `/users/search`
- Дополнительная точечная фильтрация по возрасту и телефону (клиентская, в рамках текущей загруженной страницы)
- Модальное окно с подробной информацией о пользователе: ФИО, возраст, адрес, рост, вес, телефон, email, аватар
- Изменение ширины колонок (drag, минимальная ширина 50px)
- Обработка ошибок HTTP-запросов
- Юнит-тесты на Vitest (API-слой и MobX-стор)

## Архитектура

- `api/` — слой работы с Fetch API, изолирован от компонентов и стора
- `stores/` — MobX-стор с бизнес-логикой (сортировка, пагинация, поиск, фильтрация, выбор пользователя)
- `components/` — переиспользуемые компоненты (таблица, модалка, подсветка совпадений, фильтр колонки)
- `types/` — TypeScript-интерфейсы

## Особенности реализации

- Основной поиск реализован как единый серверный запрос по всем полям (`/users/search`), а не отдельные инпуты под каждой колонкой — API dummyjson не поддерживает независимую серверную фильтрацию нескольких полей с частичным совпадением одновременно. Дополнительно добавлена точечная клиентская фильтрация по возрасту и телефону.
- Поле "отчество" отсутствует в данных API dummyjson — колонка не выводится.
